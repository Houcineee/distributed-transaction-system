# Origin-adapted design system

Adapted from the Inspo extraction of https://useorigin.com. This project uses the design DNA, not the source content or layout verbatim.

- **Mode:** light
- **Macrostructure:** marquee-led product dashboard
- **Tone:** elegant, airy, high-contrast fintech
- **Palette:** deep origin blue, pale sky surfaces, ink navy, muted blue rules
- **Typography:** Instrument Serif for display; Manrope for interface copy; DM Mono for technical labels
- **Spacing:** 4px base, with 8 / 16 / 32 / 48 / 60 / 96px anchors
- **Radius:** 8px controls and panels, pill-shaped actions
- **Motion:** restrained opacity and transform transitions; reduced-motion support required
- **Product constraint:** preserve the existing backend contract and banking workflows
